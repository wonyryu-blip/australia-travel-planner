# 우리의 호주여행

[웹사이트 열기](https://wonyryu-blip.github.io/australia-travel-planner/)

호주 여행의 일정, 예약, 지출을 한 곳에서 관리하는 반응형 정적 웹사이트입니다.

## 포함 기능

- 대시보드: 여행 기간, 날짜별 일정, 예약 현황, 예산, 체크리스트
- 날짜 상세 / 개별 일정 상세 / 예약 상세 / 지출 상세 페이지
- 일정·예약·지출 추가, 수정, 삭제
- 예약 상태 필터와 검색, 지출 분류 필터와 검색
- AUD/KRW 지출 합산, 수동 환율 설정, 결제자별 합계
- 여행 시작일 변경 시 날짜 일괄 이동
- 브라우저 저장, JSON 내보내기·가져오기, 공유 링크 복사

## 테스트 자료

2027년 4월 10~16일 시드니·멜버른 7일은 가상 일정입니다. 실제 여행 정보가 아닙니다.
일정 14개, 예약 6건(확정 4건·예약 필요 2건), 지출 6건이 포함됩니다.
환율은 1 AUD=900원의 예시값이며 실시간 환율이 아닙니다.
초기 총지출은 3,406,500원, 예산 6,000,000원, 잔액 2,593,500원입니다.
예약 금액은 지출 합계에 자동 가산하지 않습니다. 결제가 이루어지면 지출에 별도로 기록하세요.

## 공유 및 저장 방식

웹사이트와 저장소는 공개입니다. 링크를 받은 동반자는 동일한 게시 자료를 볼 수 있습니다.
웹사이트에서 수정한 자료는 현재 브라우저 localStorage에 저장됩니다. 서버나 GitHub에 자동 반영되거나 동반자에게 실시간 동기화되지 않습니다.

수정 자료를 공유하려면 **여행 설정·공유 → 자료 내보내기**로 JSON 파일을 저장한 후 동반자에게 전달하세요.
동반자는 **자료 가져오기**로 불러올 수 있습니다. 가져오기는 해당 브라우저의 자료를 교체합니다.
실제 예약번호·여권번호·결제정보 등은 공개 소스 코드에 올리지 마세요. 브라우저 데이터 삭제 전 JSON 백업을 권장합니다.

## 실행 및 배포

별도 빌드나 의존성 설치 없이 `index.html`, `style.css`, `app.js`로 실행합니다.
로컬 미리보기: `node server.cjs` 후 http://127.0.0.1:4173
검사: `node --check app.js` 및 `node test.cjs`
GitHub Pages: main 브랜치의 루트 디렉터리를 게시합니다.
Noto Sans KR 글꼴을 Google Fonts에서 불러오며, 연결이 안 되면 시스템 글꼴로 표시됩니다.

## 유지관리

게시 기본 자료는 `app.js`의 `seed` 객체에 있습니다. 이미 로컬 자료를 저장한 브라우저는 새 기본 자료 대신 로컬 자료를 유지합니다. 최신 기본 자료가 필요하면 백업 후 테스트 자료 초기화를 이용하세요.
